EVO2 DNA Foundation Model Demo

A working StripedHyena-based neural architecture for long-context DNA sequence modeling.

GitHub repository

Overview

About the project

This demo implements a compact StripedHyena-inspired architecture for DNA sequence modeling. It combines multi-scale convolution, attention, character-level nucleotide tokenization, and a complete training workflow.

Highlights

What it delivers

  • Models short, medium, and long-range patterns in biological sequences.
  • Includes training, validation, checkpointing, and loss visualization.
  • Demonstrates a working DNA foundation-model pipeline on CPU or GPU.
