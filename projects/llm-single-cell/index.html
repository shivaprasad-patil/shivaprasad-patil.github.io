LLMs and Foundation Models for Single-Cell Analysis

An exploration of combining biological foundation models with LLMs for cellular reasoning.

GitHub repository

Overview

About the project

This project explores how single-cell expression profiles can be represented as language-like sequences. A compact Cell2Sentence-style demo shows how biological foundation models and local language models can support cellular reasoning.

Highlights

What it delivers

  • Encodes gene-expression profiles into sentence-like representations.
  • Explores cell-type annotation and perturbation-response prediction.
  • Provides a small training example for understanding the architecture from first principles.
